# On Custom Commands

In the next lecture, I introduce "Custom Commands". As I mention there, "Custom Commands" and "Skills" have overlapping purpose. So you can use "Skills" instead of "Custom Commands".

Indeed, for that reason, the "Custom Commands" feature has essentially been merged with "Skills". I.e., it still exists, you still can use it as shown in the next lecture BUT, as I also mention there, you could also use just "Skills".

For that reason, the official Claude Code documentation no longer explicitly explains or mentions "Custom Commands". Hence this lecture, so that you don't wonder where that feature went. It's still there but you may simply just use "Skills" instead.
